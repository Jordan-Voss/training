# Training design system

Working concept: `/workspace/generated_images/exec-a10efcab-ae5c-41a2-95b0-d4a0b18c9b3f.png`.
The supplied brief is authoritative where illustrative prescriptions differ.

System typography; headings 28/34, section 22/28, body 16/23, secondary 14/20,
labels 12/16. Font scaling stays enabled. Tabular numerals for results.
Spacing 4, 8, 12, 16, 24, 32, 40. Corners 8 and 12; 1px dividers. Minimum target 44px.
Light tokens: #F7F8FA, #FFFFFF, #15181E, #5A6472, #2457F5, #EAF0FF, #E4E7EC.
Dark tokens: #0F1115, #191C23, #F2F4F8, #A5ADBA, #779CFF.

Desktop: 200px navigation rail, bounded main, 2:1 Today columns, notebook
tables, open history timeline. Phone: stack and bottom tabs, single-column
notebook with per-set controls and secondary details. Thin outline icons.
No gradients, decoration, or fake statistics. No central image assets needed.

Allowed primary copy: Training; Today; Programme; History; Profile; current
programme, round and sequence metadata; Day 1; Squat, push & pull; Start workout;
Choose a session; Up next; Other training; Local demo; Saved on this device.
Additional fields and screens are required by the brief and use the same tokens.
Fixtures never become personal records on sign-in. Imports retain source text.
